## 1. 结论

4W53（T4 lysozyme L99A + toluene）ΔG_bind 算出 **+9.21**，实验 **−23.10 kJ/mol**，
误差 **+32.31 kJ/mol**。

这个误差 **不是**下面任何一项造成的（均已逐条排除）：热力学循环闭合、Boresch
限制与解析释放、λ 布点、估计器（MBAR/BAR/TI 三方一致）、采样量（见 §3.2）。

**根因**：IBS 的 stage2 每个窗口只跑**一条**轨迹，窗口内所有 λ 态靠重加权覆盖。
配体消失时蛋白空腔要塌缩、水要灌进去 —— 这是**结构性慢模态**，单条在某个 λ 上
平衡出来的轨迹采不到重组后的构型。缺的是空腔重组的熵项。

## 2. 为什么所有收敛门都没报警

**这是本根因最危险的部分：现有全部收敛门对这个失效模式失明。**

门判的是"这批样本内部自洽吗"。单系综漏掉整个构象态时，剩下的样本在自己内部
**完全自洽**：ESS_ratio 0.92–0.98、absolute_ESS 上千、split-half 前后半程一致
（前后半程漏的是**同一个**构象态）、MBAR/BAR/TI 三方一致（三个估计器吃的是同一批
缺构型的帧）。

**实测钉死这一点（溶剂腿，唯一有独立参考真值的腿）：**

| 量 | 值 |
|---|---|
| mixture overlap | 0.4684（判优） |
| **raw** overlap | **0.0196** |
| `converged` | **True** |
| stage2 报出的 ΔG | **+35.61 kJ/mol** |
| 独立参考 ΔG_LJ（原始，**无 LRC**） | **−6.29 ± 0.34 kJ/mol** |
| 独立参考 ΔG_LJ（**+LRC 校正 +2.746**，口径匹配） | **−3.544 ± 0.34 kJ/mol** |

`converged=True`，误差 42 kJ/mol。**门全绿 ≠ 数对。**

根因在于 mixture 覆盖度把**共模因子除掉了**：它证明的是"已采到的帧在窗口内各 λ 态
之间分得开"，不是"这批被 Group-4 λ-WCA 防护壳偏置过、整窗只有一条轨迹的采样能
重加权到真实物理系综"。所以求解器侧才把 **raw 绝对 ESS 与权重集中度**升级为硬门。

## 3. 推论：哪些工作不会修好 ΔG

### 3.1 加门 / 调门槛不会
门不改变任何被算出来的数，只改变"什么时候中止"。

### 3.2 加采样不会；而且慢模态在能量上几乎不可见
window 2 相邻态 ⟨ΔU⟩ 仅 **0.4–0.6 kT**，却贡献约 **21 kJ/mol 的 TΔS**。
→ 只用能量序列估自相关时间会系统性低估 g、高估独立样本数，也就是
"稳定地收敛到错值"的统计学版本。（`_decorrelate_independent_record` 因此在
能量序列与逐帧空腔水数两个候选里取**更差**的那个。）

2026-09-01 `output_v3_seed20260908` 的实测（同一天跑了 4 遍 production rescue，
250k → 500k → 1M）：

| 窗口 | absolute_ESS | raw_target_ESS（门槛 20） | top1%_raw_weight |
|---|---|---|---|
| window_2 | 365 → 704 → 1232 | 1.33 → 1.53 → **2.12** | 0.88–0.96 |
| window_4 | 458 → 949 → 1851 | 3.79 → 4.75 → **2.63（反降）** | 0.86–0.92 |

样本翻两番，raw 支撑度纹丝不动甚至倒退。**瓶颈是 ensemble span / 重加权尾巴，
不是帧数。**

### 3.3 空腔水判据在复合物腿上不是状态函数
`count_cavity_waters` 把探针锚在**配体**上。λ_vdw→0 时幽灵配体与环境无 LJ、
只被 Boresch 松松拴着、会漂 —— 它测的是"幽灵当前漂到哪、0.24 nm 内有几个水"，
不是空腔水合度。实测同一 0.24 nm 探针内蛋白重原子比水还多，最近蛋白原子
0.095–0.259 nm。

v3 进一步钉死：同一个 λ 上 s1|w1 转变 **181 次**、s1|w0 **零次**；同分布下单段干
驻留 ≥500 帧的概率 ≈ exp(−500/1.54) ≈ **1e-141**。
**再多采样、再换种子都修不了 —— 那是观测量的问题，不是采样量的问题。**

要恢复以空腔水为判据的装置，**先把探针锚点从配体换成蛋白腔壁参考原子**，
让它重新成为状态函数。在那之前恢复它只会再烧一轮 GPU 得到同样无判别力的结果。

## 8. 修复方向

### 8.2 独立端点采样（每个 λ 各自跑独立轨迹）
这是针对 §1 那个 +32 kJ/mol 根因的**正面修复**：末段不再由一条轨迹重加权覆盖，
而是每个 λ 态独立平衡、独立采样，让空腔塌缩/进水这个慢自由度在各自的系综里
真正有机会发生。

实现：`ibs_engine.solve_independent_endpoint_states()` +
`combine_ibs_and_independent_endpoint()`。

**⚠️ 2026-09-01 现状：整段默认关闭（`stage2_independent_endpoint=False`）。**

必须说清楚三件事，别混为一谈：

1. 关掉的**不只是**干/湿双起点那个诊断装置（那个装置的问题在 §3.3：判据锚点错了），
   而是**整段独立端点采样**，也就是本节这个正面修复本身。
2. 关它的理由是**运行代价**，不是"问题已解决"：8 条逐态轨迹约 90 分钟且整段不打
   日志，在 4W53 上是最大单项耗时，而它当时挂着的判据（§3.3）没有判别力。
   这是使用者在 2026-09-01 的明确决定。
3. **代价：末窗口回到 §1 那条已知会给错答案的路径。+32 kJ/mol 没有被修好。**
   任何在此配置下产出的复合物腿 ΔG 都只是推进流程的中间量。

要重新启用：`stage2_independent_endpoint=True`（窗口数不足时 fail-closed）。
重新启用前应先按 §3.3 改掉探针锚点。

## 9.1 ⚠️ 用溶剂腿参考真值之前必读（2026-09-01 补，abfe-ibs-d5 复核）

仓库里到处转述的「独立参考真值 ΔG_LJ = −6.26 ~ −6.29 kJ/mol」有两个坑，
**直接拿它减会得到错的误差**：

**坑一：那是 no-LRC 值。** 出处 `4W53/toluene_hydration_reference.py:300`
（变量名 `dG_decouple`，标签「态0 -> 态K-1」——方向是**解耦**，与管线 stage2 一致，
这点没问题）。但管线的 stage2 **含 LJ 长程尾项**（`build_ibs_dual_system` 逐 λ_vdw
算尾项系数，`IBSSampler` 每帧加进 `target_energies`）。
`4W53/STAGE2_GROUP5_CUDA_PBC_ROOT_CAUSE_2026-08-29.md` §8.2.1 给了校正：

```
Beutler 参考（原始，无 LRC）      = -6.290 ± 0.340
Beutler 参考（+LRC 校正 +2.746）  = -3.544 ± 0.340   ← 与管线口径匹配的靶子
```

**坑二：Group5 是另一件事，别跟本文件的根因混。** 2026-08-29 定级、08-30 修复的
Group5（配体 COM 限制力 `CustomCentroidBondForce`，非周期绝对锚点，且**只**加在
溶剂腿）是**独立采样路径**的异常来源，现已修复
（`ibs_engine.LIGAND_COM_RESTRAINT_PROTOCOL_VERSION = 2`，Group 5 现为空组）。
它**不是**本文件 §1 那条单系综根因。

**两条路径在同一条腿、同一份修复之后的对照（这是目前最硬的证据）：**

| 估计器 | ΔG_LJ | vs 靶子 −3.544 |
|---|---|---|
| ACE **独立逐 λ 采样**（08-30，72 walker×12 态） | −3.414 ± 0.246 | **0.31σ 一致 ✅** |
| IBS **单系综重加权**（09-01，纯 IBS 3 段链） | **+38.59 ± 0.576** | **+42.13，63σ ❌** |

同体系、同 Group5 修复、同 λ 网格，**唯一差别是逐态独立采样 vs 单轨迹重加权**。
这就是 §1 根因第一次被定量隔离出来，量级 **≈ 42 kJ/mol**。
（09-01 的 stage2 走的是纯 IBS：`solvent_leg/final_results.json` 里没有
`independent_endpoint_segment`，`combine_ibs_and_independent_endpoint` 从未运行 ——
正是 §8.2 记的那个「默认关闭」决定的直接后果。）

**推论**：`stage2_independent_endpoint=True` 在这条甲苯溶剂腿上重跑，应当回到 ≈ −3.4。
那会是同体系、同代码的直接 A/B，是把单系综缺陷钉死的最短路径。
⚠️ 但 2026-09-01 干/湿双起点已被退役成死代码
（`ibs_engine.WET_DRY_DIAGNOSTIC_RETIRED = True`），而 08-30 那次 0.31σ 用的是
湿干各半 72 walker，现在重跑只有 dry-only 36 walker，复现不出原样的 −3.414。
要不要临时复活湿臂是**使用者的决定**，不是代码该自己改的。

**最后：ΔG_bind 的配平。** 只把溶剂腿 LJ 修到 −3.544 ⟹ ΔG_bind 从 +12.75 变成
**−29.39**（实验 −23.10，误差 **−6.29**）—— 仍然冲过头，说明复合物腿的 vanishing
（+59.47）也被同一机制抬高了约 6 kJ/mol 量级。**两条腿必须一起修，只修一条会让
总数看起来更差。**
