### 3.0 ⚠️ 这张表**不能**读成「八道门反了」

三条限制，缺一条都会把它读过头：

1. **门本身的逻辑没有反。** 「ESS 高 = 重加权条件化得好」是正确的统计。
   反的只是它与**实验偏差**之间的符号 —— 而那不是这些量声称要预测的东西。
2. **九道门不是九份独立证据。** 两两 Spearman |ρ| 中位 **0.77**、最大 **0.94**、
   36 对里 26 对超过 0.7；秩相关矩阵第一主成分解释 **78%**，解释 90% 只要 2 个。
   ⟹ 九道门约等于 **2 个独立方向**。「八道反号」实质是「大约一个方向反号」，
   重复数了八遍。
3. **n=6 下没有一条显著。** 双侧 0.05 需要 |ρ| > **0.88**，实测最大只有 **0.657**。

**能站住的结论是「测不到关系」，不是「关系反了」。** 区别要紧：
反了的话把符号翻过来还能用，测不到则翻了也没用。
而「测不到」这一条**不依赖 n=6** —— 它有 §3.2 的机制理由。

### 3.2 为什么反号是可预期的，不是数据少

这些**全是精度量**：它们量「在已采到的系综上，这个估计量条件化得好不好」。
与实验的偏差是**准确度**问题：力场、循环里缺的项、单系综抓不到的重组熵。
**ESS 门与力场误差之间没有任何机制上的联系**，所以符号乱是应该的。

仓库自己记过同一件事：`STAGE2_ROOT_CAUSE_2026-08-28.md`
「所有收敛门对这个失效模式失明」。

## 4. 窗口层：n = 170

### 4.1 哪个量预测窗口支撑

| 预测量 | ρ(·, rawESS) | ρ(·, top1%) | |
|---|---|---|---|
| ∫g | **+0.022** | −0.096 | **无信号** |
| L = ∫√g | −0.417 | +0.304 | 中等 |
| ΔF | −0.141 | +0.186 | 弱 |
| K | −0.431 | +0.357 | 中等 |
| **窗口序号（λ 路径位置）** | **+0.518** | **−0.403** | **最强** |

```
控制窗口序号后：ρ(K, rawESS | pos) = −0.106      ← K 的独立贡献塌了
控制 K 后：      ρ(L, rawESS | K)  = −0.175
                 ρ(∫g, rawESS | K) = −0.173
剔除每份结果的 w0（n=133）：ρ(K, rawESS) = −0.349
```

**占主导的是窗口在 λ 路径上的位置**（耦合端难、解耦端易），不是 K、不是任何路径积分。

### 4.2 噪声底

同体系、同窗位的 `raw_min_absolute_ess` 跨度（22 组）：**中位 1.8×，最大 31.6×**。
与 abfe-ibs-61 在同 seed 同配置下实测的 `min N_eff/g` 34× 一致。

⟹ **ρ = −0.11 在这个噪声下没有决策价值。**

### 4.3 ⚠️ 撤回

本日早些时候我基于 **n=29**（只用跑完的 6 个 rep）给出过：

> 「ρ(K, rawESS) = −0.607 最强；控制 K 之后 L 与 ∫g 归零 ⟹ **K 是唯一带信息的变量**」
> 「剔除 w0 后 ρ(K, rawESS) = −0.703，所以不是『w0 难』是『K 大难』」

**n 扩到 170 之后这两条都不成立**：K 降到 −0.431，控制窗口位置后只剩 −0.106，
剔除 w0 后降到 −0.349。原来那个数是小样本 + K 与 w0 高度共线（ρ = −0.709）放大出来的。

**仍然成立的**：∫g 没有信号（+0.022，与 §5 的推导互相印证）。

## 5. ∫g 退役的依据是推导，不是这批数据

λ 布点按等热力学长度 δ 放（**23 个 rep 实测 max/中位 = 1.09–1.19**）。于是：

```
等 δ ⟹ Δλ = δ/√g
每条边的 ∫g ≈ g·Δλ = δ·√g      ← 对已经等长的边再按 √g 加权一次
L_window = Σδ ≈ δ·(K−1)         ← 长度就是态数，不是独立变量
```

**布点这一步的全部意义就是把度规吸收掉。分窗再按 ∫g 均衡 = 把度规用两遍。**
这条不依赖上面任何相关系数；实测 ρ(∫g,·) ≈ 0 只是与它一致。

### 5.1 那 2026-09-17 那次分窗改动（`metric_integral` → `state_count`）还成立吗

**成立，但理由要换**：

- ✅ ∫g 该退役 —— 数学上重复计数，实测无信号。
- ⚠️ 换成 min-max K 的正当性**不是**「K 是预测量」（§4.3 已撤回），
  而是它把**最难的那一段（耦合端）均匀压小** —— 恰好作用在真正占主导的变量上，
  但这是**间接的**。
- ❌ 「K 是唯一带信息的变量」撤回。
- 🔬 **仍然完全没有真机验证。** 全部是窗口之间的观察相关，不是干预实验。

## 6. 结论

| 对象 | 判断 |
|---|---|
| ESS / overlap / top1% **作为诊断** | 对。它们确实量重加权条件数 |
| 同上 **作为验收门** | **不对**。测不到与误差的关系（**不是**「符号反了」，见 §3.0）；且九道门只有约 2 个独立方向 |
| 全部阈值 | **一个都没标定**，其中一条的报错文本自承无依据 |
| 主验收量 `min N_eff/g ≥ 10` | **当前预算下不可分类**（单次读数横跨整个量程） |
| 自报 σ | **低估 2.1×**；同一批帧重分析一次就漂 ~1σ；且与实际误差反号 |
| `precision_status`（跨重复 SD ≥3 重复） | **口径是对的**，但现在量到的是布局漂移 —— 控制器给每个 rep 分了不同的窗 |
| ∫g 作为分窗目标 | **数学上错**（重复计数），已退役 |
| 窗口难度的真实主导量 | **λ 路径上的位置**（耦合端），不是 K、不是路径积分 |
| ΔG 的真实问题 | **系统性偏负 ~8 kcal/mol，8/9 同号** —— 上面任何一道门都看不见 |

**唯一诚实的处置：全部门降级成报告，`publishable` 不挂在它们上面。**
力气回到那个 −8 kcal/mol 的系统偏移 —— 审计热力学循环，这是唯一动得了它的东西。
