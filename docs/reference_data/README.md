## `stage2_vanishing_truth_toluene_2026-09-02.json`

甲苯水合的 λ_vdw 解耦段（stage 2）真值：甲苯（15 原子）在纯水中，4208 原子 / 4193 约束。

> ⚠️ **这份真值跑在建系盒上（43.95 nm³），比 1 bar 平衡密度低约 3%。** 同 λ 表、同 seed
> 换到生产 NPT 平衡后的盒（42.75 nm³），`m2n2` 的 ΔG_LJ 从 −6.581 ± 0.256 变成
> −11.490 ± 0.342 kJ/mol（差 −4.9 kJ/mol）。**要和生产比，必须在同一密度下比**；
> 本文件保留用于留痕和下面那条软核指数自检。

### 怎么产生的

完整独立实现（生成脚本不在本仓库）：自己建 alchemical system，**每个 λ 各自平衡 + 生产、
不做重加权**，pymbar MBAR。CUDA / RTX 2080 Ti / mixed，每态 100k 步平衡 + 500k 步生产 @ 1 fs
（500 样本），另有 200k 步全耦合预平衡。NVT，盒固定为建系盒。

### 两份，因为软核指数必须匹配才能逐窗口比

| key | λ 前因子 / 分母 (1−λ) 指数 | ΔG_LJ (λ_vdw 1→0, kJ/mol) |
|---|---|---|
| `m1n1` | `λ¹` / `0.5(1−λ)¹ + (r/σ)^6` | −6.818 ± 0.245 |
| `m2n2` | `λ²` / `0.5(1−λ)² + (r/σ)^6` —— **与生产一致** | −6.581 ± 0.256 |

自检：两者差 0.237、合并 σ 0.354，0.67σ 一致。理论上端点（λ=1 为精确 LJ、λ=0 为 0）与指数无关，
所以总量必须一致。

### 用法

1. **要跟生产逐窗口比，只能用 `m2n2`。** `m1n1` 的中间态是不同的哈密顿量，只有总量可比。
2. **两份都不含 LJ 长程（尾项）修正**，生产 stage 2 含。直接相减是在比两个不同的哈密顿量。
   用 `tools/diagnostics/attribute_stage2_solvent_leg_gap.py`（只读、不用 GPU）：它从运行产物
   直接读出该次运行实际施加的尾项（`energies.npy − sampling_states.npy.T` 是逐 λ 态的常数），
   并自动反解生产盒体积、在密度不一致时告警。
3. **逐窗口比要把真值插值到生产的 λ。** 真值的 λ 表与生产实跑差 0.001–0.007；在 dF/dλ 很陡的段，
   这点差就能造出约 1 kJ/mol 的假残差。上面的工具已代做。
4. **`per_state_Delta_f_kT` 是相对态 0 的累积值，单位 kT（T = 300 K）**，乘 2.49434 得 kJ/mol。
5. JSON 里 `_attribution_2026_09_02` 一块的 `single_mixture_reweighting_kJ_mol` 和
   `total_error_production_minus_truth_kJ_mol` 相减前没有对齐尾项，**不要引用**；
   `wca_shield_kJ_mol` 两边都不含尾项，不受影响。JSON 本身保持原样（实验数据不改）。
