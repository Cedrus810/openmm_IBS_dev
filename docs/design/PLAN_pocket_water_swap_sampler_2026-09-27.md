## 1. 不变的部分：热力学环

对态 X（apo = 复合物腿 λ=0：鬼影配体 + Boresch；holo = λ=1）：

```
F_X = F_X(N) + kT ln P_X(N)          （条件自由能与完整自由能的恒等式）

ΔG°_bind = ΔG_bind(N*) + kT ln P_holo(N*) − kT ln P_apo(N*)
```

- N = 口袋区域 R 内的水氧个数；R 是配体无关的小球并集，刚性跟随蛋白（09-18 §8 的定义）。
- **两端必须是同一个 N\***，`G_A(N*)` 才消得掉。
- 溶剂腿不受影响。
- 这条恒等式成立的前提是 `ΔG_bind(N*)` 是**真正的条件自由能**，也就是 ABFE 全程 N 被约束在 N\*。
  09-18 版只在初始构型里放 N 个水、不约束 ⟹ 实际上是赌 N 被动力学冻住（09-18 §6 自认「嫁接」）。
  v2 用区域墙把这一步做严格，见 §5。

### N\* 取 holo 的主导值

- λ=1 时配体占掉 R 的大部分，能容的水远少于 apo（jnk1_ligand1：R 的体相当量 16，holo 只剩几个）。
- 取 `N* = argmax P_holo(N)` ⟹ holo 修正小（P 尖时接近 0，但要算出来验证）。
- apo 修正 `kT ln P_apo(N*)` 是大项，而且 **N\* 落在 P_apo 的尾巴上**（可能 1e-4 量级）。
  ⟹ 直方图直接数拿不到，必须带偏置 g(N)（§3.3）。草稿 §16 的「直接直方图、不需要 MBAR」
  对 ⟨N⟩ 成立，对闭环要的量不成立。

## 2. 从 SwapMC 拿什么、不拿什么

| 拿 | 不拿 | 理由 |
|---|---|---|
| 总水数不变的 bulk↔口袋搬水 | —— | 不需要 μ_ex / B_eq / B 阶梯 / 幽灵水拓扑 |
| 一次生成大量候选、并行算能量 | 「按固定顺序取第一个通过 Metropolis 的候选」 | 见下 |
| Gumbel-max 做加权选水（提速阶段） | 用反应场能量直接做接受判据 | 采到的是 RF 哈密顿量的分布，不是生产 PME 的；v2 用 delayed acceptance 修回（§3.4） |
| 搬水后重置被移动水的速度 | 速度清零 | 改成从 Maxwell–Boltzmann 重抽再施加刚性约束（§3.5） |
| —— | 把搬水挂进整条 ABFE 生产 | v2 仍在离线态上采 P(N)，ABFE 只加墙（§5） |

### 为什么 first-accept 不行

固定选中的水 i，按顺序试 M 个候选、取第一个通过的：从 x 转到 y 的核是

```
K(x→y) = p_i(x) · g(y) · a(x→y) · [1 − (1 − Ā(x))^M] / Ā(x)
```

Ā(x) 是从 x 出发单次候选的平均接受率。反向对应的因子是 Ā(y)，两者一般不等 ⟹ **细致平衡被破坏**。
只在 Ā·M ≪ 1 时因子 ≈ M、近似抵消；恰恰是容易接受的（开阔、易水化）态被带偏。
⟹ 用标准 MTM（Liu–Liang–Wong 2000），正反向 Rosenbluth 权重都进接受率。

### 文献给的预期（校准用，不当目标）

- ABFE（JACS 集）：JNK1 RMSE 2.01 → 0.77，**P38 无改善**（3.22 → 3.25），PTP1B/CDK2/TYK2 降 44–49%。
- BPTI 埋藏水：默认间隔（1000 步）10 ns 内**零次成功插入**，间隔调到 100 步才进去。
  ⟹ **深埋口袋的接受率是本线最大风险**，S1 先量。

## 3. 采样器

目标分布：态 X 的 NPT 正则分布（apo 或 holo，与 ABFE 端点同一个哈密顿量，含 Boresch），
可选乘偏置 `e^{g(N)}`。MD 与 MC 交替：每 n_MD 步做一次 MC 移动。

### 3.1 移动：搬水（Move A）

- 等概率选方向：in（R_out → R）或 out（R → R_out）。
- 源水按 `p_i ∝ exp(βu_i)` **能量加权**选（论文 eq 1）。~~均匀选、加权押后~~：S1 实测均匀选源不可行（§8）。
  加权选源下单候选接受率化简为 `A = (V_in/V_out)·Z_out(x)/Z_in(y)`，`Z = Σ_k exp(βu_k)` 对源区域求和，
  被搬水自身能量抵消；代价是每次移动都要全体水的逐水相互作用能（GPU 核，§8）。
- 目标区域内生成 K 个候选（位置在目标区域内**严格均匀** × 随机四元数取向；水的内部几何原样复制，保证刚性约束满足）。
- 候选能量 = 被移动的那个水与其余所有粒子的相互作用能（只动一个分子 ⟹ ΔU 精确等于新旧相互作用能之差）。

### 3.2 接受率（MTM）

以 in 移动为例，x = 源水旧位置，{y_1..y_K} 为 R 内候选，w(·) = e^{−βu(·)}：

1. 按 w(y_j)/W_fwd 选出 y，W_fwd = Σ_j w(y_j)。
2. 反向参考集：在 R_out 里另抽 K−1 个均匀候选，加上旧位置 x，W_rev = w(x) + Σ w(ref)。
3. 接受率

```
A = min{ 1,  [W_fwd / W_rev] · [V_in / V_out] · [N_out / (N + 1)] · e^{g(N+1) − g(N)} }
```

   out 移动对称写出。**这条式子在实现前要单独推导一遍并写成单元测试**（草稿 §18 Test 4），
   不要照抄本节。

   ⚠️ 上式是**均匀选源**版。S1 之后改为能量加权选源（§3.1），K=1 时接受率为
   `A = (V_in/V_out)·Z_out(x)/Z_in(y)·e^{g(N+1)−g(N)}`；加权选源与 K 候选 MTM 合用时，反向选源概率含
   `e^{βu_y}/Z_in(y)`，依赖被选中的候选，**不能直接把上式的 N 因子换成 Z 比**，须单独推导。

注意 out 方向的候选落在稠密体相里：随机位置大多与水重叠，W 由少数好位点主导，
**两个方向都需要 K 个候选**，S1 两个方向都要量。

### 3.3 N 偏置 g(N)

- 预热期用 Wang–Landau 类自适应把偏置下的 P(N) 压平，**进生产前冻结**（生产期自适应会破坏平稳性）。
- `P_phys(N) ∝ hist_biased(N) · e^{−g(N)}`。
- 这一步替代了 09-18 的 B 阶梯 + GCI/MBAR：一条带偏置的轨迹覆盖从 N\*（holo 值）到 apo 平衡值的整段。

### 3.4 便宜势 + delayed acceptance（S7，押后）

- 第一级：用便宜势 U_0 跑整个 MTM（U_0 必须是整个构型的良定义函数，例如全体系反应场 + 截断，
  不能是「只算附近几个原子」这种随候选变的近似）。MTM 对 π_0 满足细致平衡。
- 第二级：`α_2 = min{1, exp(−β[(U(y)−U_0(y)) − (U(x)−U_0(x))])}`，U 为生产 PME。
- 两级合起来平稳分布是生产哈密顿量的（Christen–Fox）。验证：与只用精确能量的版本 P(N) 一致（草稿 Test 5）。

### 3.5 速度

被移动的水：从 Maxwell–Boltzmann 重抽原子速度 → `context.applyVelocityConstraints()`。
这是对动量的部分 Gibbs 刷新，不影响构型分布。

### 3.6 区域中心的定义（与 §5 共用，**必须同一个函数**）

09-18 用衬里 CA 的 Kabsch 跟随。v2 改成 OpenMM `LocalCoordinatesSite` 可表达的局部坐标系
（由几组衬里 CA 的质心定原点和轴），理由：§5 的墙要在 OpenMM 力里算球心，Kabsch 写不进力表达式。
**MC 采样器里判定 N 用的球心，必须与 ABFE 墙用的球心是同一个定义**，否则 P(N) 和
ΔG_bind(N\*) 的 N 不是同一个东西（与「位点聚类全局冻结」「区域配体无关」是同一类跟头）。
球心之间保持刚性 ⟹ V_in 恒定。

## 4. 必须保留的诊断

- 每个 N 内的网络标签 η：位点从汇总密度聚类**一次、全局冻结**；网络 × N 计数矩阵；P(η|N) 是否多峰、是否互通。
- 滞后：从干口袋起和从湿口袋起各跑一条，P(N) 必须重合。
- N 的积分自相关时间、N 空间往返次数、驻留时间。**效率指标用 ESS_N / GPU·h，不用接受率。**
- 收敛门对慢变量失明（09-18 §6）——本线有效性不由流水线自己的门认证，只由 S6 认证。

## 5. ABFE 期间的 N 约束（区域墙）

复合物腿**所有窗口**加一组平底墙，把 N\* 个指定的水关在 R 里、其余水挡在 R 外：

| 对象 | 力 | 能量 |
|---|---|---|
| 球心 | `LocalCoordinatesSite` 虚拟粒子（跟随衬里 CA，§3.6） | —— |
| N\* 个「内水」 | `CustomCompoundBondForce`（每个内水 + 全部球心） | `k · max(0, min_s(|r − c_s| − R_s))²` |
| 其余「外水」 | `CustomNonbondedForce`，interaction group = 球心 × 外水氧 | `k · max(0, R_s − r)²`（逐球相加，在任一球内即受罚） |

- 给水贴标签引入的组合因子 C(M, N\*) 在 λ=1 与 λ=0 两端相同 ⟹ 在 ΔG_bind(N\*) 里相消。
- 墙有限刚度 ⟹ 与指示函数定义的 N 有边界层差异。验证：两个刚度（如 k 与 4k）下 ΔG_bind(N\*) 一致。
- P_X(N) 在**不加墙**的态上用 §3 采样器算，N 的判定用同一套球心。
- 副作用（中性记录，不当主因推）：墙存在时，w3/w4 里溶剂灌进鬼影配体体积的那个盆
  （[记忆] 09-23 双稳态）在 ABFE 里不存在，这个自由度被挪进 `P_apo(N*)`。
  但 09-27 HREX 末帧显示蛋白也会侵入鬼影体积，墙挡不住蛋白塌陷；λ=0 端口袋只剩 N\* 个水，
  塌陷风险（BPTI 型）可能更大。

⚠️ **这一步改生产哈密顿量**：
- 墙参数必须进 `stage_protocol_key`（是物理身份，不是执行历史），开启即作废复合物腿全部窗口缓存。
  落地前按规矩先查指纹、把 GPU 代价摆给用户。
- 加虚拟粒子 = 改粒子数。管线里依赖原子数/原子索引的地方（坐标旁车、Boresch 索引、分析脚本、
  resume 指纹）要先盘点。可选方案：虚拟粒子放在 System 末尾、全部 mass=0、不进任何已有索引表。
- 开关默认关；关着时生产行为逐位不变（要有测试）。

| holo（λ=1） | 1–3 | −32 / −15 | −27 ~ −36 | ~10⁻¹¹ | **2.5×10⁻⁹** | 4×10⁻⁵ |
| apo（λ=0） | 11–17 | −32 / −13 | −18 ~ −25 | ~10⁻¹¹ | **2.1×10⁻⁵**（in 与 out 相等） | **0.22**（逐帧 10⁻⁵ ~ 0.9） |

读法：
1. **均匀选源不可行**：体相水 βu ≈ −32，随机口袋位点极少做到同样好，K=8192 时接受率仍 ≤10⁻⁶。
2. **加权选源把门槛从「典型体相水」降到「最弱的水」**（约 −13 ~ −19 kT），apo 每候选接受率升 6 个数量级；
   in 与 out 两个方向的平均接受率相等，符合平衡态下的通量平衡，说明估计自洽。
3. 接受率在帧间重尾（同一口袋，不同快照差 5 个数量级）⟹ 必须按「每次尝试的候选数 × 尝试频率」算期望，不能看单帧。

### 成本结论

| 路线 | apo 每次被接受移动 | 对比 GCNCMC 37 s |
|---|---|---|
| Python + 精确能量（1.8 万候选 × 2.8 ms） | ~230 s，**另加** Z 需要 2.4 万个逐水能量（× 45 ms ≈ 18 min/次） | ❌ 差 1–2 个数量级 |
| 批量逐水能量核（按论文 4090 上 2 ms/次尝试，**未在本机实测**） | ~10 ms | ✅ 好 3 个数量级（估算） |

⟹ **S2 的「精确能量原型」在生产体系尺寸上跑不动**。调整：
- S2 的正确性测试改在小体系上做（纯水盒 ~1000 水，CPU/numpy 参考实现逐水能量即可）。
- 生产体系上直接走 S7 的批量核 + delayed acceptance（核里用便宜势 U_0 算候选与 Z，只对选中的候选做一次 PME 修正）。
- holo（λ=1）即便有核也约 50 s/次接受；但 P_holo 只需要 N\* 附近，且 holo 的 N 小，预期够用，S3 验证。

### 对测试体系的影响（jnk1_ligand1 不适合当 S6 的验收对象）

- **S0 已塌**：09-24 复现批 3 rep −11.34 / −12.32 / −12.74 kcal（SD ≈0.7），7.8 kcal 散布是 09-23 修复前的产物。

  是一个约 11 个水体积的干腔，蛋白塌陷风险高（§7 #4）。

## 9. S1 on BRD4（2026-09-28，用户 5090 上跑；输出 `abfe-benchmark/openmm_IBS/pocket_water_s1/`）

用户定的 go/no-go：① 口袋在动力学上确实埋藏 ② 加权选源 + 1.8 万候选的批量接受率不至于极小
③ apo/holo 有可用的共同 N\* ④ 常规 ABFE 有 ≳1–2 kcal 的跨 rep 散布。备胎 HSP90_Kung（不回 JNK1）。

输入：brd4_ligand2 rep1–3（09-23 复现批的 pre_equil 末态），对照 jnk1_ligand1 rep1（只做 ①③）。
两种区域：`lig` = 配体埋藏重原子小球并集（R 0.30）；`site` = holo 预平衡里占据率 ≥0.6、离配体 ≤0.5 nm 的
持久水位点（R 0.14），BRD4 每个 rep 8 个位点，JNK1 6 个。每态普通 MD 1 ns（丢前 100 ps），逐 ps 追踪水的身份，
进出判定带 0.3 nm 缓冲。

⚠️ 探针脚本当时有 bug：每帧第二个源水的自身能量算错（Context 没从上一个源的候选坐标恢复），
那一半行作废，已修（`ctx.setPositions(pos)`）。下表只用第一个源水的行（3 rep × 10 帧）。
09-27 jnk1 的 §8 数字不受影响（那版脚本在该水关闭状态下算 E_off，与其位置无关）。

### ① 动力学埋藏

| | lig 区域 apo：每水每 ns 换水次数 | site 区域里 900 ps 内一次都没换过、占据率 ≈1 的位点 |
|---|---|---|
| JNK1 rep1 | 23 | 0 个（最慢的一个占据率 0.58） |
| BRD4 rep1 / 2 / 3 | 29 / 30 / 30 | holo：4 / 3–4 / 4；apo：0（换了 1–8 次）/ 2 / 4 |

- **配体体积那块（lig）在 BRD4 里补水和 JNK1 一样快**（apo 每水每 ns 约 30 次，完整一次驻留中位数约 20 ps）。
- **BRD4 有约 4 个真正的慢水**（保守水网络），JNK1 没有。但它们在 holo 和 apo 里**都满占**、3 个 rep 起点都在、
  彼此一致 ⟹ `P(N_slow) ≈ δ(4)` 两边相同，`kT ln P` 两项都 ≈0，也没有 rep 间差异可修。
- 其余位点（占据率 0.4–0.8）每 ns 进出几十到一百多次，普通 MD 已经采到。

### ② 加权选源的接受率（精确 PME，K = 18000）

| 区域 / 态 | 每候选接受率 均值（中位数） | 一批 1.8 万候选至少接受一次 均值（中位数） |
|---|---|---|
| lig / holo | 4×10⁻⁸（9×10⁻¹¹） | 0.001（2×10⁻⁶） |
| lig / apo | 1×10⁻⁵（2×10⁻⁸） | **0.10**（3×10⁻⁴）；JNK1 为 0.22 |
| site / holo | 3×10⁻⁷（~10⁻¹⁸） | 0.006 |
| site / apo | 6×10⁻⁸（~10⁻¹⁸） | 0.001 |

site 区域的「进」几乎总被拒，因为位点多半已被占（往已占的 0.14 nm 小球里放水就是重叠），这是物理，不是方法失败。
lig/apo 与 JNK1 同量级（约低 2 倍），重尾。

### ③ apo/holo 的 P(N) 重叠

| 区域 | holo N | apo N | Bhattacharyya | 共同 N\* |
|---|---|---|---|---|

### ④ 跨 rep 散布

brd4_ligand2 新 LCR 控制器（09-27）−13.76 / −11.97 / −14.13 kcal，SD ≈1.2；09-23 旧控制器 SD ≈1.5。
（之前引用的 2.06 是转述错误。）

### 判定

- lig 区域：① 不过（补水和 JNK1 一样快），③ 不过（结构上必然）。
- site 区域：③ 过（N\* = 6），① 只对 4 个慢水成立，但它们两态都满占、各 rep 一致 ⟹ 没有可修的采样问题。

  HSP90 不在现有 benchmark（现有：brd4 / cmet / cyclod / jnk1 / p38 / thrombin），需要先准备结构和 Amber/GAFF 参数。
