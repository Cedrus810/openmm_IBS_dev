## 1. 要修的是什么

同一体系不同 rep 的 ΔG 差远大于各自内部误差：

| run | ΔG (kcal/mol) | 内部 ± |
|---|---|---|
| jnk1_ligand1/rep1 | −2.38 | 0.81 |
| jnk1_ligand1/rep3 | −10.19 | 0.85 |

跨 rep 差 **7.81**，内部只有 **0.8**，差一个数量级。这是**慢自由度在单条 run 内被冻住、
在 run 之间取了不同值**的签名，不是随机噪声。口袋水占据/氢键网络正是这种自由度，
亲水口袋尤甚（水多、氢键网络强、重组势垒高、亚稳网络多）——JNK1 和 P38 因此被选作实验对象。

两条直接后果：

- **多跑 rep 求平均救不了。** 各 rep 不是从正确分布抽的样，是从「预平衡碰巧落进哪个盆」
  抽的，权重与真实布居无关。brute force 收敛到错的数、误差棒还在缩。
- **内部 ± 不能当体系不确定度报。** 它量的是「这条 run 的网络有多稳」，网络越冻它越小，
  与可靠性反相关。

## 2. 链条

```
[巨正系综，离线]                         [NVT，常规]
GCMC/GCI/MBAR ──→ N, P(N), 网络布居 ──→ 幽灵水开关 ──→ 常规 ABFE ──→ +kT·ln P 补回
   口袋区域                                 (setup)        (水不碰 λ)
```

1. **GCMC/GCI/MBAR 离线跑**，巨正系综，只作用在口袋区域上 → P(N)、网络布居、ΔG(N)
2. 在 **B_eq** 上读出 N 和占据向量
3. **幽灵水开关**把 N 落实到 ABFE 初始构型（预置 N_max，多余的关成幽灵）
4. **常规 NVT ABFE**，水不碰 λ，全程没有巨正则
5. 口袋水贡献用 `ΔG_hyd(X) = kT·ln P_X(N)` 补回
6. 网络简并（主导态 <90%）时多起点按 MBAR 网络布居加权

**两边只通过一个整数 + 一组初始坐标接触。** 接口在 **setup**，不在采样循环里。
`f_k`、收敛门、窗口缓存全部按 NVT 定义和验证，本方案一律不动。

### 明确不做的三件事

| 不做 | 为什么 |
|---|---|
| 每个 λ 窗口挂 GCMC（全程陪跑） | 把本来正常的窗口的系综也换了。为修一个坏端点去动全部好的态 |
| λ=0 端点插 MC 移动 | GCMC 跟 λ 没有任何关系；它只负责回答「几个水、概率多大」 |
| 逐个水炼金术插入求 ΔG(N) | 各步误差平方和累积；且它答不了网络简并 |

## 3. 闭环公式

定义 `ΔG_hyd(X)` ≡ 把 X 态区域的水从固定 N 放开到平衡的自由能：

```
ΔG°_bind = ΔG_bind(N固定) + ΔG_hyd(holo) − ΔG_hyd(apo)
```

推导：`G_C,eq = G_C(N) + ΔG_hyd(holo)`、`G_A,eq = G_A(N) + ΔG_hyd(apo)`，代入
`ΔG° = G_C,eq − G_A,eq − G_L` 即得。**前提：两项里的 N 必须是同一个 N**，`G_A(N)` 才消得掉。

### 接口比看上去更干净

`ΔG_hyd` 不需要另算：

```
ΔG_hyd(X) = kT · ln P_X(N)
```

因为 `P(N) ∝ e^{−β(ΔG(N) − μN)}`，放开态自由能为 `−kT ln Σ_N e^{−β(ΔG(N)−μN)}`，
减去约束态 `ΔG(N) − μN`，即 `kT ln P(N)`。**整个 apo 修正就是「apo 口袋装 N 个水」
这件事的概率的对数**，MBAR 边缘化到 N 直接给出。

它自动复现了「holo 端 ≈ 0 但要验」：P 尖（0.9）⟹ −0.06 kcal/mol；大口袋配体旁能容水
⟹ P_holo 宽 ⟹ 不成立。**「验」的具体操作就是看 P_holo(N_holo) 有多大。**

⚠️ `μ_ex` 已在 B 里，不要手动减。

## 4. B 阶梯怎么筛

**范围**——两个锚点框住：

- 下锚：B 低到 ⟨N⟩ → 0（空腔）。这是 ΔG(N) 的积分常数来源，不能省。
- 上锚：B_eq（纯水盒同体积校准出来的值，此处 ⟨N⟩ = ρ_bulk·V），再往上 2–3 个单位确认进平台。

**间距**——有解析判据，不用试。由 `∂⟨N⟩/∂B = Var(N)`：跨一步 ΔB，均值移动
`Var(N)·ΔB`；该态 N 分布宽度 `σ_N = √Var(N)`。要相邻态重叠：

```
Var(N)·ΔB ≲ √Var(N)   ⟹   ΔB ≲ 1/σ_N
```

自适应：陡坡 σ_N ~1.5–2 ⟹ ΔB ~0.5；平台 σ_N ~0.7 ⟹ ΔB ~1.4。**B 不等间距铺，按 1/σ_N 铺。**
15 个单位跨度大致对应 20–30 个 B 态。

**流程两轮**，不是一轮设计好：

1. 粗扫 5–6 个 B，故意铺宽、每个跑短，只为拿 ⟨N⟩(B) 的 sigmoid 形状和逐点 Var(N)
2. 按 1/σ_N 加密，跑正式长度
3. overlap matrix 收口

粗扫的帧全部保留、一起进 MBAR，不浪费。粗扫的作用是让加密只需一轮而不是五轮。

**两个容易埋雷的点**：

- **答案只在 B_eq 上读。** 其余 B 都是脚手架，存在意义是给 MBAR 足够重叠把统计量搬到 B_eq。
- **hydration site 从汇总密度聚类一次、全局冻结**，所有 B 共用同一套位点。各 B 各自聚类的话，
  占据向量这个标签在 B 之间不可比，MBAR 出来的 network 自由能是假的。
  （与「腔区域定义必须配体无关且逐 rep 相同」是同一个跟头。）

## 5. GCI 与 MBAR 不是采样交叉验证

两条路共用同一批帧，但吃的信息量不同：GCI 只吃每个 B 的**一阶矩 ⟨N⟩**（丢掉态内 P(N)，
完全不碰 U）；MBAR 吃**逐帧 (U, N)** 加态间重叠。MBAR 信息严格更多，所以**可以**不一致——
这就是这个检查的有效性来源，但它的射程只到这里：

| 对不上能抓到 | 对上了**不能**保证 |
|---|---|
| GCI 拟合函数不够（logistic 和捕捉不到真实形状） | 构型空间的洞 |
| B 铺太疏，积分求积误差 | B 校准/区域定义是否系统性错（两条一起继承） |
| MBAR 自洽解没收敛 / 重叠太差 | 全部 run 同一初始构型、从未逃出同一个盆 |
| 单个态 ⟨N⟩ 本身没收敛 | |

**「对不上 → 采样有洞」这个推断太强**：最可能是前三条（机器问题）。
而**要抓的正是网络陷落 = 构型空间的洞 = 这个检查唯一瞎的那一类**。

### 真正的洞检测器（需要独立信息）

1. **滞后。** B 阶梯从空腔往上爬跑一遍、从满腔往下退再跑一遍。两条 ΔG(N) 不重合 ⟹ 有陷落。
   这是唯一动了初始条件的检查，而初始条件正是造成陷落的东西。
2. **占据向量 × B 计数矩阵。** 统计每个网络标签在每个 B 下出现多少帧。**只在一个 B 里出现过的
   网络没有任何冗余支撑**——MBAR 照样给一个数，但这与「相邻 B 不重叠时 MBAR 照样解出数但没意义」
   是同一回事，只是从 N 空间搬到网络空间。

overlap matrix 管阶梯上的洞，计数矩阵管网络上的洞。**要的是后者。**

## 6. 为什么叫「猴子补丁」：水占据是慢变量

ABFE 那条腿**不在平衡系综上**（困在一个盆里）。拿 GCMC 的平衡量去接它是**嫁接**，不是修正——
热力学环的两条腿都假设是平衡态，这里有一条不是。严格性只在「占据向量恰好完整捕捉了那个慢流形」
的极限下成立，而那是**假设，不是定理**。

三条后果：

1. **收敛门全部失明。** block 平均、ESS、`f_k` 残差、split-half 量的都是快自由度的抖动；
   一个从不移动的变量它们看不见。**跑得越像收敛，越可能是困得越死。**
   ⟹ 本补丁的有效性**不可能由流水线自己的门来认证**。
2. **归属映射本身是近似。** `Σ w_i·ΔG_bind(network i)` 要求把一条 run 判给某个 `network_i`，
   但 run 可能中途漂过、可能停在 GCMC 集合里没有的构型上，也可能网络标签之外还有别的慢自由度
   （与水网络耦合的侧链）一起冻着。`w_i` 从 GCMC 来、`ΔG_i` 从 ABFE 来，两边的 i 不保证是同一个东西。
3. **验收只能是经验的，不能是形式的。** 唯一有意义的判据见下节。**不存在「证明它对」这条路。**

## 7. 实验：JNK1 与 P38

### 唯一验收判据

**加上补丁之后 σ_跨rep 塌不塌。**

- 塌了 ⟹ 占据向量抓住了那个慢变量
- 不塌 ⟹ 慢流形比占据向量大，补丁没打在点上

不要用「ΔG 更接近实验值」当判据——单点接近可能是抵消。要打的是 **7.81 kcal/mol** 的散布，
不需要任何精度。

### W0 结果

**μ_ex = −5.986 ± 0.117 kcal/mol，V_std = 0.03053 nm³**
（TIP3P；PME / 1.0 nm / HBonds / rigidWater / 300 K / NPT；20 λ × 500 样本；25 min）。

grand 写死的 TIP3P 默认是 −6.09 / 0.030345 —— 自己算的两个都在误差内一致。

⚠️ **μ_ex 与 GCMC 跑在同一个哈密顿量上，但那不是生产的哈密顿量。**
`calc_mu_ex` 内部构造 `BaseGrandCanonicalMonteCarloSampler`，其 `__init__` 就调
`customiseForces()`（软核 sterics + `setUseDispersionCorrection(False)`）。所以 B 自洽，
但生产 ABFE 开着色散校正。色散校正是均匀密度项，对口袋/体相的**相对**占据影响应极小，
**这是把 N 交回生产时的一个已知近似，不是 bug**。

### 区域几何：球并集，不是单个球

单个外接球罩不住激酶 ATP 位点这种长条沟（配体 r_max 0.72–0.99 nm 而 mean 只有 0.41–0.51），
一半伸在体相里。改成**小球并集**，小球心 = 配体的埋藏重原子，R_sub = 0.30 nm
（配体重原子 vdW ≈0.17 + 水半径 ≈0.14 = 水氧能占据的排空体积）。

| case | 单球当量 | 并集当量 | 小球数 | V_union (nm³) | B_eq |
|---|---|---|---|---|---|
| jnk1_ligand1 | 37.7 | **16.0** | 13 | 0.488 | −7.27 |
| jnk1_ligand2 | 57.9 | **21.4** | 16 | 0.653 | −6.98 |
| p38_ligand1 | 47.1 | **15.6** | 10 | 0.475 | −7.29 |
| p38_ligand2 | 84.2 | **25.2** | 17 | 0.770 | −6.83 |

椭球试过（解析体积 + 解析均匀采样，代码少一半），但在 jnk1_ligand2 上胀到 **2.08×**
（该配体分叉）。一套方法要吃四个 case，所以用并集。

**接受率数学不用改**：`exp(B)/(N+1)` 与 `N·exp(−B)` 对任意区域形状都成立，只要
(a) 插入在区域内均匀、(b) B 里的 V 就是该区域体积、(c) 成员判定一致。grand 里这三处
只在 4 个地方（`initialise:761` / `updateGCMCSphere:864` / `insertRandomWater:911` /
`__init__:584`），子类覆写即可。

小球心之间保持刚性、整体 Kabsch 跟随衬里 CA ⟹ **V_union 恒定**，这是 B 里那个 V
能当常数的前提。参考原子取蛋白 CA（配体无关），apo/holo/各 rep 是同一个区域。

### 顺带修的 grand 两个问题

1. **`updateGCMCSphere` 是 O(N_waters²)。** `setWaterStatus` 每次调用做全表 `np.where`，
   而更新循环逐水调它。本体系 23613 个水 ⟹ 每个 GCMC move 约 5.6 亿次操作。已整体向量化。
   （grand 的例子都是小体系，所以没暴露。）
2. **explosion 路径会把 NaN 坐标喂给区域更新。** `insertionMove` 在 `break` 之后、
   恢复**之前**就调 `updateGCMCSphere`（`samplers.py:1358`）。grand 单球版能活是因为
   `norm(NaN) <= R` 只返回 False；Kabsch 会直接抛 SVD not converge。已加 NaN 容忍：
   退回上一组好的球心，NaN 水坐标自然判为区域外 ⟹ 该 move 被拒，语义与 grand 一致。

### 踩过的两个真 bug（别重犯）

1. **`initialise` 必须在 `minimizeEnergy` 之前。** 反过来 EM 会在幽灵水还是真水、
   且与真实水重叠的状态下跑，把体系拧坏（首跑就是这么炸的）。与仓库记过的
   「EM 跑在 Boresch scale 生效之前 ⟹ NaN」同形。
2. **每个协议档必须重建 System。** `customiseForces` 是**就地**改 System 的：
   原 NonbondedForce 所有粒子 ε 清零、真实 sterics 搬进新建的 CustomNonbondedForce。
   同一个 System 上跑第二次，第二个 custom force 拿到的全是 ε=0 ⟹ sterics 整个消失
   ⟹ 满屏 explosion、接受率 0。首轮探针的第 2/3 档就是这么作废的。

### 输入派生

复合物腿的体系来自用户的 `.gro/.top`，光改 OpenMM Topology 不会让 System 多出粒子。
幽灵水按仓库既有的 reserved co-ion 同一套做法派生（`runabfe.py:2106`）：
`[ molecules ]` 末尾追加 `HOH n`、`.gro` 末尾追加同样数量的水原子行。
GROMACS 的原子顺序就是 `[ molecules ]` 的展开顺序，**两边都追加在末尾**才不会错位；
重复的分子名在 `[ molecules ]` 里合法。原始文件一个字节不动。

λ=0 态的实现：建好 System 后把配体的非键（电荷、ε，含 exception）清零 ⟹

## 9. W1 接受率探针结果与成本结论（2026-09-18，分支在此暂停）

### 实测数据

jnk1_ligand1，复合物腿 λ=0 态（配体非键清零），并集区域 V=0.488 nm³，B_eq=−7.269，
77k 原子全盒，RTX 2080 Ti mixed precision。explosion 全程 0。

| switching (ps) | nPert × nProp | 接受 | 接受率 | s/move | **s / 每次接受** |
|---|---|---|---|---|---|
| 0.45 | 9 × 25 | 1/200 | 0.5 % ± 0.5 % | 0.71 | 142 |
| 0.95 | 19 × 25 | 7/200 | 3.5 % ± 1.3 % | 1.28 | **37** |
| 1.9 | 19 × 50 | 12/260 | 4.6 % ± 1.3 % | 2.26 | 49 |
| 4.9 | 49 × 50 | 1/60 | 1.7 % ± 1.7 % | 5.46 | 328 |
| 9.9 | 99 × 50 | 1/60 | 1.7 % ± 1.7 % | 10.91 | 655 |

误差是 Poisson。**可以说的**：0.45 ps 塌掉；0.95 与 1.9 ps 在误差内相同；
**加长 switching 买不到接受率**。⚠️ 4.9/9.9 ps 那两行只有 60 个 move，与 1.9 ps 相差
约 1.5σ，分辨不出，**不能读成「越长越差」**。

⟹ **最优 switching ≈ 1 ps，每次被接受的插入约 37 s。**

### 成本外推 —— 这是估算，不是测量

前提（**未实测，本节唯一的软处**）：N 每次接受移动变 ±1，走过 σ_N ≈ 2–3 需要
~4–9 次接受才算一个独立样本；要 ~200 个独立样本 ⟹ **1000–2000 次接受/B**。

在此前提下：**12–20 GPU·h 每个 B** × ~20 个 B（由 §4 的 `ΔB ≲ 1/σ_N` 定）× 4 个 case
⟹ **~1000–1600 GPU·h**，单张 2080 Ti 是 6–9 周。

**σ_N 与「需要多少次接受」都还没测过。** 第一个真实 B 扫描跑完即可把该估算钉死；
在那之前**不要把 1000–1600 当结论引用**。
