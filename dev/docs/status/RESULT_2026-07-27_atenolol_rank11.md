## 7. 排查结论：哪些被排除、哪些是根因

| 假设 | 结论 | 依据 |
|---|---|---|
| MBAR / λ 阶梯 / REMD 混合有问题 | ❌ 排除 | TI 独立复现：复合物 50.30 vs MBAR 49.51；溶剂 63.70 vs 62.72（均差 ~1 kJ） |
| 渐近协方差在此样本量下失效 | ❌ 排除 | 生产求解逐窗 `absolute_ess` 全部 ≥ 26（那个 1.0 是 warmup 期 `last_tmbar_update` 的量，不是生产解） |
| 误差棒被低估 | ❌ 排除 | 同一 λ 区间 11→15 的两个独立估计：老 w3 `8.8779±1.4934` vs rescue `11.0566±0.3279`，**z = 0.89** |
| 拓扑丢电荷 / 两腿电荷集不同 | ❌ 排除 | Σq² 两腿 15 位有效数字相同（5.026599401151067 vs …65）；itp 直接求和净电荷 = +0.000000 e，Σq² = 5.026599401 |
| 两腿 decharging 方法不同 | ❌ 排除 | 均为 `pme`，同 `model_version = pme_decharge_v2_llfreeze_pmeself_20260523` |
| P1-13 污染自相关 | ❌ 排除 | base 序列 21 处不连续，但真正估 g 的 `(u_kn[k]−bias)/kT` **0 跳变**；且 `grep -c "触发回退\|灾难检测触发"` = 0，那些不连续来自跨进程续跑边界 |
| 配体在预平衡里漂走 | ❌ 排除 | 无约束预平衡末帧 RMSD **0.60 Å**、质心 **0.17 Å**（口袋骨架对齐） |
| **Boresch 平衡值陈旧（P0-10）** | ✅ **根因** | 带 Boresch 的 rebalance 后 RMSD **3.42 Å**、质心 **2.46 Å**；committed 值与轨迹实测偏离 0.13/4.23/3.97/23.65/21.29/15.93 σ |

关键的纯系综证据（不经任何自由能机器）：配体-环境静电相互作用能
⟨ΔU⟩@λ=1 在**水里 180.92 kJ/mol、口袋里 144.04 kJ/mol** ——
配体在口袋里静电上比在水里差 36.9 kJ/mol。参考值要成立，这个数得反过来。

**为什么三项里只有 vdW 对得上**：vdW 对取向不敏感（配体仍然埋着、接触面积几乎不变），
而静电依赖方向性氢键、restraint 直接吃错的 r0/sinθ。这个组合本身就是"埋着但取向错"的指纹。
