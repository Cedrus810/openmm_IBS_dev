# Stage 2 λ 调度契约（协议 v18）

## 唯一 λ 的生成

1. 用真实 λ pilot 测量 `β² Var[∂U/∂λ]`，按 Fisher 热力学长度生成 17 个常规节点；禁止使用累计 `|ΔF|` 排点。
2. 常规节点全部保留，不删除、不移动。
3. 在常规边 `0→1` 内插入 1/4、1/2、3/4 三点，在常规边 `1→2` 内插入中点。
4. 最终为 `λ0..λ20` 共 21 个唯一节点，并强制 `λ0=1`、`λ20=0`。

## 窗口画线

人类使用闭区间：

```text
[0, 5]    6 个状态
[5, 9]    5 个状态，只共享 λ5
[9, 13]   5 个状态，只共享 λ9
[13, 17]  5 个状态，只共享 λ13
[17, 20]  4 个状态，只共享 λ17
```

Python 使用等价半开区间：

```python
[(0, 6), (5, 10), (9, 14), (13, 18), (17, 21)]
```

因此共有 21 个唯一 λ、4 次公共边界复用、25 个窗口采样槽位。每条 λ 边只属于一个窗口；任何相邻窗口共享两个节点、任何把最后节点写成半开端点 20 的实现都必须拒绝。
